# mscfgutil
This script is designed to help scripts and users to edit their configs.
# requirements
- toml library
# usage
You can use this script as a module. <br>
__COMMAND__ usage: `\mscfgutil <set|read|view>`
# Documentation of functions
## `write_to_config(key, new)`
Write to the config.
## `read_from_config(key)`
Read from the config.
## `get_config(key)`
Get from the config.
